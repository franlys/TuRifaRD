# Mapa de Habilidades del Asistente (skills.md)

Este archivo describe las capacidades técnicas y herramientas del desarrollador de IA asignado a este proyecto.

## 1. Habilidades Frontend

- **Arquitectura de Componentes**: Creación de componentes altamente reutilizables con React o Vanilla Web Components.
- **Animaciones de Alto Rendimiento**:
  - Animaciones SVG y CSS para el **reloj animado**.
  - Canvas o CSS 3D Transforms para la **ruleta interactiva de participantes**.
  - Efectos de confeti y transiciones fluidas de estados.
- **Responsividad y UX**: Diseño Mobile-First (especialmente enfocado a teléfonos móviles, de donde provendrán la mayoría de los usuarios de rifas según los mockups provistos).

## 2. Habilidades Backend e Integraciones

- **Gestión de Base de Datos**: Modelado relacional para rastrear usuarios, boletos generados, transacciones pendientes y premios de rifas.
- **Sistemas de Archivos y Carga**: Implementación segura de carga de imágenes (capturas de pantalla de depósitos).
- **Notificaciones por Correo**: Configuración de plantillas HTML responsivas y elegantes para correos de:
  - Confirmación de compra (boleto reservado).
  - Confirmación de pago (boleto validado con número de ticket oficial).
  - Alerta de inicio de sorteo en vivo (enlace para ver la ruleta).
- **Lógica de Sorteo Seguro**: Algoritmo criptográficamente seguro para la aleatoriedad de la ruleta, garantizando transparencia.
